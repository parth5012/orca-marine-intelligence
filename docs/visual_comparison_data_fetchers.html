ORCA Data Pipeline: Architecture Transition

Comparison of Data Fetchers Before and After Integrating Open-Meteo APIs & In-Memory Static GIS

BEFORE Integration

Fragile & Stubbed
Weather Agent (Wind / Pressure) Blocked / Stubs
• backend/routers/weather.py raises NotImplementedError
• Dependent on approval for IMD portal credentials or heavy scraping
• Fallback to static mock heuristic
Sea State Agent (Waves / Swell) Fragile Sessions
• Relies on INCOIS OSF HTML scraping
• Requires dynamic JSESSIONID daily session cookies
• Fails or blocks thread when session expires
Danger & Geofence Agent Disk I/O Latency
• Reads multiple large GeoJSON files from disk on every query
• Missing standardized IMBL buffer file
• Fallback point distance calculation without strict boundary verification
Cyclone Safety Advisory Silent Omission
• No live barometric pressure evaluation
• If bulletin feed is offline, reports "Safe" by default (dangerous blind spot)

AFTER Integration

Operational & Fast
Weather Agent (Open-Meteo Forecast) Zero-Auth Live API
• 10m wind speed, gusts, direction, precipitation, surface pressure
• Parallel non-blocking async request (asyncio.gather, 6s timeout)
• 30-60 min Redis cache with coordinate rounding (round(lat, 2))
Sea State Agent (Open-Meteo Marine) Dedicated Wave Models
• Live significant wave height, wave period, swell direction & height
• Fetched concurrently with weather in same I/O burst
• Returns verified nautical metrics into lexical masker
Danger Agent (Static In-Memory GIS) <15ms In-Memory
• Pre-loaded at FastAPI startup: EEZ, MPA, and 5 km IMBL buffers
• Shapely contains() & boundary.distance() in RAM
• Instant Hard Safety Veto (DO NOT SAIL)
Cyclone Safety & Metadata Envelope Fail-Safe Disclaimers
• Auto-flags deep depressions (<995 hPa) from live surface pressure
• Transparent fallback: "Bulletin unavailable, verify official IMD"
• Provenance metadata: source, fetched_at, data_age_minutes

Pipeline Performance & Reliability Comparison

Architecture Dimension Before (Stubs / INCOIS Scraping) After (Open-Meteo + Static GIS)
External Dependency Friction High (JSESSIONID cookie expiry, IMD approvals pending) Zero (Public Open-Meteo API, static local GIS)
Network Execution Model Serial blocking requests / unhandled exceptions Concurrent asyncio.gather() with 6s timeout
Geofence Verification Latency 150ms – 400ms (Repeated disk I/O JSON loads) < 15ms (Pre-loaded Shapely objects in RAM)
Cache Strategy None or unkeyed session store Redis TTL cache keyed on round(lat, 2) (~1.1 km cells)
Safety Failure Handling Silent "No Alert" if cyclone bulletin offline Explicit warning: "Bulletin data unavailable; verify IMD"
Evidence / Provenance Unstructured dictionaries Standard envelope (source, fetched_at, data_age_minutes)
